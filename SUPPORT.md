# Support / 支持

Report reproducible problems at
[ymote/octosense-github-notes issues](https://github.com/ymote/octosense-github-notes/issues).
Include the app version, OctoSense/runtime revision, macOS version, steps,
expected/actual behavior, and a fictional reproduction. Say whether you used a
synthetic fixture or a real provider. A redacted screenshot is useful.

Issues are public. Never post OAuth codes, tokens, private keys, account profiles,
private repository contents or unredacted logs. There is no private support or
response-time commitment. For suspected security problems, start with a minimal
non-sensitive report asking for a private reporting route; withhold exploit data
and personal information from the public issue.

请在上述仓库 issue 报告问题，注明应用版本、宿主版本、macOS 版本、操作步骤和预期/
实际结果，使用虚构内容复现，并说明是模拟提供商还是真实账户。可以附脱敏截图。
Issue 公开可见，请勿发布授权代码、令牌、私钥、配置、私有仓库内容或未脱敏日志。
当前不承诺私密支持渠道或响应时间；安全问题先用不含敏感细节的报告询问私密联系方法。
